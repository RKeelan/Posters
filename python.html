8. Classes, dataclasses

Plain class

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __eq__(self, o):
        return (self.x, self.y) == (o.x, o.y)

    def __lt__(self, o):      # enables sorted, min, max
        return (self.x, self.y) < (o.x, o.y)

    def __hash__(self):       # __eq__ alone kills hashing
        return hash((self.x, self.y))

Property and methods

class Circle:
    def __init__(self, r):
        self._r = r

        return Circle(1)

    @classmethod

        return cls(d / 2)

11. Patterns

Two pointers

def pair_sum(a, t):           # a sorted ascending
    i, j = 0, len(a) - 1
    while i < j:
        s = a[i] + a[j]
        if s == t:
            return i, j
        if s < t:
            i += 1
        else:
            j -= 1
    return None

Sliding window

seen = {}                     # char -> last index

for right, ch in enumerate(s):
    if ch in seen and seen[ch] >= left:
        left = seen[ch] + 1
    seen[ch] = right
    best = max(best, right - left + 1)

Binary search by hand

def find(a, t):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == t:
            return mid
        if a[mid] < t:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

13. Checklist

  • Read every question first; do the cheapest one first.
  • Copy the output format exactly: separator, case, trailing newline.
  • Confirm 0-based or 1-based indices before writing the loop.
  • Test empty input, n = 1, all-equal, and the largest bound.
  • Reread the constraints: n up to 1e5 rules out O(n^2).
  • Name variables for what they hold; pull repeated logic into a helper.
  • Trace the sample input by hand before running it.
  • Delete debug prints: stray output fails the checker.
  • Brute force first and submit it, then optimise. Partial credit counts.
  • Time-box each question; move on and come back.
